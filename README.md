# Cybersecurity Awareness Bot

## Application Description

The Cybersecurity Awareness Bot is a C# console application designed to help South African citizens learn basic cybersecurity awareness. The chatbot provides simple information about password safety, phishing, suspicious links, and safe browsing.

The application includes a voice greeting, ASCII cybersecurity artwork, personalised responses, input validation, coloured console formatting, and a typing effect.

## Features

- Voice greeting using a WAV audio file
- ASCII cybersecurity logo
- Personalised interaction using the user's name
- Cybersecurity questions and responses
- Password safety guidance
- Phishing awareness
- Suspicious link awareness
- Safe browsing advice
- Input validation
- Coloured console interface
- Typing effect for chatbot responses

## How to Set Up and Run

1. Clone or download the GitHub repository.
2. Open the project in Visual Studio.
3. Make sure the `welcome.wav` file is located in the `Audio` folder.
4. Build the project.
5. Run the application.
6. Enter your name when prompted.
7. Ask the chatbot a cybersecurity question.
8. Type `exit` to close the application.

## Technologies Used

- C#
- .NET
- Visual Studio
- System.Media for the WAV greeting
- GitHub and GitHub Actions

## Example Questions

- How are you?
- What is your purpose?
- What can I ask you about?
- How can I create a safe password?
- What is phishing?
- How do I identify a suspicious link?
- How can I browse safely?

A GitHub Actions workflow is included in the `.github/workflows` folder to build and check the application automatically.
